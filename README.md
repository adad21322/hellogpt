# HelloGPT 使用笔记

记录 HelloGPT 翻译器在跨境电商场景中的实操经验与避坑方法。

## HelloGPT 翻译价格和日期总出错？跨境电商客服的防坑操作笔记

做跨境电商客服或出海业务，大概率遇到过这种情况：跟客户聊得挺顺，整段话翻译也通顺，唯独价格数字多写了一个零、数量单位被换掉、或者日期从"日-月"变成了"月-日"。客户按错的数字下了单，后面就是无尽的扯皮和退款。

HelloGPT 在跨境电商场景的翻译效率很高，但涉及价格、数量、日期、账号这类关键信息时，不能完全交给"自由意译"。下面这套操作流程是从真实踩坑经验里总结出来的，不需要复杂设置，照着做就能大幅降低出错概率。

### 第一步：给关键信息"上锁"

最有效的办法，是在词库或发送规则里把这几类内容设为保持原文：

- 价格与币种：纯数字、带小数的价格、币种代码（如 USD、PHP）设为不翻译。币种全文只写一种写法，不要一会儿"美元"一会儿"USD"来回切。
- 数量与单位：把 cm、kg、pcs 等常用单位跟内部写法绑在一起录进词库，让出站翻译固定成对外标准，避免"一厘米"和"1cm"混用。
- 日期顺序：不要只写"03/04"，有的市场读成 3 月 4 日，有的读成 4 月 3 日。发交期时用"年-月-日"或带上月份名称，宁可多打两个字，也不要让客户猜。
- 账号与订单号：卡号、运单号、SKU 整串复制，发送前核对有没有被自动插入空格或变成超链接。

### 第二步：拟稿时把关键信息拆开写

翻译引擎最容易在长句子里"自作主张"。与其把价格埋在"这款含运大概和上次差不多"这种口语化表达里，不如把价格单独成句：单价多少、数量多少、是否含税，各占清楚位置。

中文拟稿时就写死数字，不要用"还按上次那个价"代替。对方说"按上次"，你回复时把具体数字再写一遍，并带上日期。两边记的"上次"不一定是同一单。

### 第三步：发送前用预览做三次快速核对

HelloGPT 在聊天窗口里通常有译后预览。不要只看句子通不通顺就发，按顺序做三个检查：

1. 数字逐位对：预览里的阿拉伯数字和输入栏是否完全一致。多一位少一位、小数点移位，都是事故。
2. 日期顺序对：你想发 4 月 3 日，预览如果变成 3 月 4 日，立刻改成带月份的写法。
3. 币种和单位对：出现合同里没约定过的货币叫法，改回去。

关键大额报价，建议先用测试号或自己的第二账号发一条，看真实气泡里显示的是什么，确认无误再给客户发。

### 已经发错了怎么办

如果错误已经发出去了，第一时间补救比解释更重要。马上补发一条更正消息，把正确的数字单独写清楚，并附上一句简短的道歉。不要指望客户自己去发现。补发的消息同样要走一遍上面的预览流程。
